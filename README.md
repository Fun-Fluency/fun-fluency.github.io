# Mentor Hub app icon & short link

This folder gives Mentor Hub a Fun Fluency icon and a short link like
https://YOURNAME.github.io/mentorhub

1. In index.html, replace PASTE_YOUR_WEB_APP_URL_HERE with the Mentor Hub web app URL.
2. On github.com, create a free account (or sign in), then New repository → name it "mentorhub" → Public → Create.
3. Click "uploading an existing file", drag in ALL the files in this folder, then Commit changes.
4. Settings → Pages → Branch: main, folder / (root) → Save. After ~1 minute your link appears at the top.
5. In MentorHub.gs, set LAUNCHER_URL to that link, Save, then Deploy → Manage deployments → ✏️ → New version → Deploy.
